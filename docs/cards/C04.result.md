# C04 result

## Summary

- Added deterministic valuation for PPF, EPF/VPF, SSY, SCSS, MIS, gold, bonds, NPS, insurance, traditional policies, savings, ULIPs, and property.
- Added a Decimal price-provider protocol with static overrides, EMI and loan amortisation helpers, and Decimal XIRR/policy IRR calculations.
- Extended asset schemas and synthetic rate fixtures, added default cached rate loading, and regenerated the exported JSON Schemas.
- Added coverage for each non-loan `AssetType`, missing prices, default rates, and the card's anchor cases.

## Rework

- PPF and SSY maturity projections now include simple interest through the current financial year's 31 March credit before projecting remaining April-to-April periods.
- PPF and SSY use the latest earlier scheme rate when the requested date is uncovered; EPF uses the latest earlier declared FY rate. Each fallback adds a `using latest available rate from ...` note, and valuation raises `RateUnavailable` when no earlier rate exists. Locked-at-purchase schemes retain strict lookup.
- Matured traditional policies now use the maturity illustration when available, otherwise the premiums-paid estimate, and add `matured: confirm the amount received and close this policy`.
- Added regression tests for both projection fixes, floating-rate fallbacks and missing-history errors, strict NSC lookup, and both matured-policy branches.

## Decisions / open issues

- The loan API has no required valuation month in its specified three-argument signature, so `amortise` accepts an optional `start: MonthYear` and defaults it to the current month; payoff is reported as that month plus the payment count.
- `policy_irr` uses exact 365-day intervals between annual policy cashflows, consistent with actual/365 XIRR and the required return anchor. Policy maturity market value for SGB is left unset because the card provides no future gold-price projection.
