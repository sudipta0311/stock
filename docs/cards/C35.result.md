## Decisions / open issues

- Packs without a valid ISO week leave index history unavailable; this keeps older or incomplete checkpoints loadable.
- Python's default private temp-directory mode is inaccessible in this Windows sandbox. Recursive cleanup of the generated restricted temp directories was blocked by environment policy, so pytest used a temporary directory-mode shim and ignored only stale generated CAS fixture directories. The focused C35 regression set passed; the full suite remains blocked by PostgreSQL recovery.
