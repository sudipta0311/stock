- Added owner-controlled `app_resolve_user`, a `SECURITY DEFINER` upsert with a pinned search path. It returns only a UUID, lower-cases email, updates changed identity fields, and rejects a subject that differs from the active tenant context.
- Added `api_engine` validation for the `wealth_api` login and `resolve_user`; documented `DATABASE_URL`, `OWNER_DATABASE_URL`, and the one-time login SQL in the README.
- Added PostgreSQL regressions using a throwaway login and runtime-generated password.
