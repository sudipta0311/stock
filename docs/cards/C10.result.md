## Rework
- AMFI now fetches from the [portal host](https://portal.amfiindia.com/spages/NAVAll.txt) first and falls back to the [www host](https://www.amfiindia.com/spages/NAVAll.txt). Added offline coverage for the primary path and timeout fallback.
- ECB is now the primary FX source. It joins matching daily EUR/INR and EUR/USD observations, computes USD/INR to four decimals, stores `ECB (EUR cross)` plus both source URLs, and falls back to FRED. The fixture test verifies 2026-10-27 at 95.1242.
- The NSE master refresh now combines the equity list and official [ETF list](https://nsearchives.nseindia.com/content/equities/eq_etfseclist.csv). ETF rows receive gold, debt, global-equity, or India-equity sleeves; a failed ETF-list fetch is recorded while equity rows still load. Added official-format fixtures and a DB-backed refresh test proving NIFTYBEES, JUNIORBEES, and GOLDBEES closes are stored. AMFI updates also preserve NSE ETF identity when an ISIN overlaps.
- Stabilized the existing import concurrency test by creating its user before parallel requests, so the test measures parser serialization without racing first-time user creation.
