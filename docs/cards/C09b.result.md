## Decisions / open issues
- Kept `IN` and `INR` for existing Indian imports and added `GB` for London listings. The supported currency list includes INR for that existing flow.
- No broker column presets were seeded: Saxo and Danske help pages describe exports but not their column headers, and Nordnet's public API docs do not document statement export columns. Danish and other undocumented files use `needs_mapping`. [Saxo export help](https://www.help.saxo/hc/da/articles/360039762472-Den-nye-portef%C3%B8ljesektion-i-SaxoTraderGO-og-SaxoInvestor), [Danske Bank transaction help](https://danskebank.dk/privat/find-hjaelp/investering/seneste-handler-og-transaktioner), [Nordnet API docs](https://www.nordnet.dk/externalapi/docs/api).
- The FX reference rate is an approximation of the SBI telegraphic transfer buying rate; this is documented in code and shown in tax estimate notes.
- Three older pytest temp roots remain in `.venv` (`pytest-tmp`, `pytest-tmp2`, `pytest-tmp3`). Windows denied directory access and ACL reset, so they could not be removed. The final `.venv\pytest-c09b-final` basetemp and temporary runner were removed.
