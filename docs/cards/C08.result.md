## Decisions / open issues
- `casparser` 1.4.1 installed successfully on the local Python 3.14 environment and resolved to pypdfium2 without PyMuPDF. Its package metadata declares Python 3.11+ and classifiers for 3.12–3.14; 3.12 and 3.13 were not installed locally. Its public parser consumes PDF layout objects rather than extracted text lines, so the required pure line parser interface is implemented here; the dependency remains in the `importer` extra as directed by the card.
- CDSL parsing handles text rows that expose an ISIN and complete numeric holding values. Other layouts return `unsupported_format` for review rather than inferring fields.
- Cost basis uses average cost in statement order because the card does not specify a lot-matching method.
- During the original acceptance run, `wealth_api` was manually changed to `NOLOGIN` while diagnosing the failing test. This violated the cluster-state rule and may affect local API access. An operator must verify or restore the documented production `LOGIN` state; no role changes were made during this rework.
