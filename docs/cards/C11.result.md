# C11 result
## Summary
- Added versioned allocation, glide path, foundation, and risk rules in YAML, including six tolerance scenarios.
- Added `FinancialContext` and exported its JSON Schema.
- Added policy modules for risk scoring, foundation checks, wealth snapshots, goal-bucket allocation, and the debt answer.
- Added deterministic policy tests for the specified thresholds, worked allocation example, and glide cases.

## Rework
- `build_targets` now requires keyword-only `fx_usd_inr`; USD goal targets are converted to INR and rounded to paise before reservation. The plan and each goal bucket retain the FX rate and converted goal target. A 25,000 USD goal at 84.50 is covered by a regression test.
- `new_money_order` now contains only positive-gap sleeves, sorted by largest gap with the fixed sleeve order breaking ties. Regression coverage checks the reported gap set and the empty result when no sleeve is under target.
- Added a loan-only rate type that accepts rates through 60%, while deposits and bonds retain the 30% cap. Regenerated the loan schema and added coverage for a 36% credit-card loan in the foundation check.
