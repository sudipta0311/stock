# C55 result

## Summary

- Valid ISINs with unusual or long symbols now store the ISIN as the symbol, avoiding truncation and confirm-time collisions.
- Broker parsing retains supported currencies, handles Zerodha and Saxo fields, excludes `kr` as a header unit, and still reads it as DKK in currency cells.
- Broker holding re-imports compare and replace only the selected account or broker; CAS lots across multiple accounts are left untouched unless one account matches exactly.
- Import review preserves saved templates, keeps fractional quantities exact, and leaves statement-import decisions available when broker rows cannot be added.
- Import review labels funds clearly and separates row quantities from values consistently.
- Added synthetic parser, database, UI, and Saxo e2e coverage.

## Review fixes

2. Valid ISINs replace invalid or overlong cleaned symbols without truncation; confirm and re-import tests cover both.
3. Removed the second Zerodha layout; tests cover the exact export header and IBKR's selected US/USD defaults.
4. Restored pre-C55 template header names and fingerprint normalization, pinned to the legacy fingerprint for rupee and INR headers.
5. Kept `kr` out of header-unit detection and tested that Swedish SEK values stay included.
6. Limited the no-add screen to broker imports, retained NSDL's Save decision, and added the required reason, heading, and collapsed row list.
7. Added exact quantity labels for import review while preserving default labels elsewhere.
8. Item responses now prefer the user's kind choice before payload security type and kind.
9. Removed unreachable empty-section copy and show the already-saved row count.
10. Updated Saxo e2e coverage for synthetic DKK and EUR rows, buying prices, review values, Money presence, and overflow; the review asserts DKK 60.00 and EUR 120.00.

### Round 2
