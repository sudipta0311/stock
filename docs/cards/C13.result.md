## Decisions / open issues
- `Lot` includes optional `market_price` for rebalancing and optional `maturity_date` for SGB maturity redemption. Rebalancing also accepts explicit `PricedLot` or `(Lot, sale_price)` entries. Missing sale prices prevent a sale from being proposed.
- SGB gains are exempt only when a maturity date is supplied and the sale date matches it; maturity is not inferred from acquisition date because secondary-market purchases can have a different bond maturity.
- SIP redirection changes future monthly contributions, so only immediate cash actions affect the current holdings used to recheck a breach before selling.
- C04 returns an annual return fraction; `PolicyReview.irr_pct` converts it to percentage points for comparison with the supplied PPF and FD percentages.
