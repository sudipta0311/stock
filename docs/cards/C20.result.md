### Screen-by-screen
- `/onboarding/welcome`: introduces the Money Map and starts setup.
- `/onboarding/tax`: captures tax regime, city tier, and timezone; can skip using the saved local draft.
- `/onboarding/basics`: captures monthly expenses, optional income, dependants, and employment type.
- `/onboarding/goals`: adds multiple INR or USD goals with target amounts and years.
- `/onboarding/risk`: loads six API questions, saves answers, and displays the returned risk result and constraint.
- `/onboarding/consent`: offers optional weekly email, reminder, and push checkboxes, all unticked by default.
- `/onboarding/done`: confirms setup and opens the Money Map with checklist tiles available.
- `/money`: shows net worth, completeness, upload and quick-add entry points, the 12 checklist tiles, household filters, grouped assets, liquidity/maturity/debt insights, and unvalued items.
- `/money/add/:type`: shows a generated asset form; selected checklist items advance one at a time. US investments link to the import entry point and can be deferred.
- `/money/asset/:id`: edits the saved asset, shows valuation and edit history, and offers confirmed soft close.

## Decisions / open issues
- The API has `PUT /v1/me/checklist` but no checklist read endpoint. Tile choices are stored locally and synced with the available write endpoint.
- No consent endpoint exists yet, so consent choices stay on the device and the screen says account sync is coming soon.
- Manual US investment entry is not available in the current API. The Money Map links to `/import`, whose flow belongs to C21.
- The local build used `SANDBOX_BUILD=1`; the standard Vite path is the default when unset, but its outside-sandbox build could not be exercised in this environment.
