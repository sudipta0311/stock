## Decisions / open issues
- Pinned TypeScript 5.9.3 because `openapi-typescript` declares a TypeScript `^5.x` peer range; the npm latest TypeScript 7 release could not resolve with it. Pinned ESLint 9.39.5 because the latest `eslint-plugin-jsx-a11y` peer range excludes ESLint 10.
- Used Node's native config loader and a small TypeScript API transform plugin because the workspace blocks esbuild child-process launches. The build then minifies emitted assets with Terser before running the budget check.
- Vite/PWA prints non-blocking warnings about upstream `use client` directives and the PWA plugin's deprecated `inlineDynamicImports` option; all build and budget checks pass.
