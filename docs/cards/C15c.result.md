- The live smoke found five defects the FakeRouter tests could not:
  1. Foundry rejects function tools with `reasoning_effort` on chat completions for gpt-6-luna. Tool calls now send `reasoning_effort: "none"` (router test).
  2. Hidden reasoning counts against `max_completion_tokens`, so short answers (the 64-token compliance yes/no, the 240-token valuation note) came back empty. The router adds headroom by effort (low +1024, medium +2048, high +4096).
  3. The valuation explanation's evidence came back as prose. The claim now cites the valuation tool call itself (test).
  4. A valuation sentence over 20 words failed compliance, which hands back to the Analyst, who doesn't write that text, so the dossier could only end UNRESOLVED. The valuation step now asks for one rewrite and then uses a code-written sentence (test).
  5. Sign-off approved only what the CIO model listed, and a summary that failed a wording check vetoed every eligible idea. Code now approves the top eligible ideas per market (as the card says); the model writes only the summary, replaced by a code-written one if it fails its checks (test).
- Grounding also accepts numbers that appear in cited field names ("momentum_12_1_pct" → "12-1 momentum"), but still rejects values that are only present as periods (tests).
- `RESEARCH_ENABLED` stays off until production has migrations 0021-0022.
