## Decisions / open issues
- Direct-plan sell suggestions are priced before consolidation suggestions. When an accepted sell overlaps a later consolidation candidate, the later estimate and amount use only the remaining lot quantities.
- Sale estimates start from each member's supplied TaxContext. Accepted suggestions update a request-local context for that member; members do not share an exemption.
- AMFI's [NAV history page](https://www.amfiindia.com/net-asset-value/nav-download) limits each download to 90 days, so the owner-run refresh requests bounded date windows. The 2026-10-29 snapshot had 1,149 target scheme identifiers. Sixty month-end rows each gives **68,940 rows**; at roughly 160 bytes per row including two indexes, that is **about 11.03 MB**. Actual PostgreSQL storage will vary.
- AMFI publishes TER through its [filter-based scheme page](https://www.amfiindia.com/ter-of-mf-schemes), but no stable official bulk file was found. TER remains null and the API reports `ter_unavailable`; required cost or tax estimates are skipped when data is missing.
- Worked synthetic household: the RI spouse has 9 funds, including 2 regular plans. One direct-plan check shows ₹5,000 yearly savings, a ₹500,000 switch amount, and ₹9,750 estimated tax after using ₹125,000 of the LTCG exemption; none remains. The small-company mix warns of a limit breach in 5 months. Consolidation suggests ₹500,000 with ₹32,500 estimated tax, using no exemption because the earlier direct-plan sell used it. The spouse's ₹11,000 monthly SIP is redirected. The Denmark-resident self has 2 funds; ₹5,000 and ₹3,000 monthly SIPs go to the RI spouse, with no sale suggestion. The Danish tax note stays unverified.
- One locked temporary directory remains at `.venv/temp/pip-build-tracker-n3qih2nl`. Python cleanup and `takeown` received Access Denied, and automatic command review rejected recursive PowerShell removal as blocked by policy. Pytest basetemps and other accessible temporary caches were removed.
