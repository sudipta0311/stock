## Decisions / open issues

- The stored rate source URLs fetched during this run are `https://www.indiapost.gov.in/banking-services/savings` (NSC, KVP, RD, PPF, SCSS, MIS, and SSY) and `https://www.epfindia.gov.in/site_docs/PDFs/Circulars/Y2025-2026/DeclarationOfROI_2024_25.pdf` (EPF FY 2024-25). The Department of Economic Affairs small-savings page, `https://dea.gov.in/budget-division/475`, was used to confirm the active Q3 FY 2026-27 period (2026-10-01 through 2026-12-31).
- `td_1y`, `td_2y`, `td_3y`, and `td_5y` remain empty because the fetched current India Post page gives only a 6.9%–7.5% range without mapping each rate to a TD term. `value_po_td` accepts the certificate rate for those periods.
- The EPF reference contains FY 2024-25 only. No FY 2025-26 value was added without an officially declared rate source.
- Every real reference entry has `verified: false`, as required. Post-office RD treats the existing `PostOfficeAsset.amount` as the monthly installment because that schema has no separate RD installment field. KVP still requires a purchase-date reference entry for its maturity month count, even if an asset rate is supplied.
