# C64 result
## Summary
- Added a pure safe-moment check for applying a waiting service worker update.
- Updates apply automatically within 15 seconds of page load or return when no field changed, no dialog is open, and the offline save queue is empty.
- Unsafe or unknown states keep the existing refresh toast; visibility-triggered `registration.update()` remains in place.
- Added lifecycle tests for automatic application, each toast fallback, tap-to-refresh, and visibility update checks.
- Added a quiet Settings footer with the seven-character build commit and UTC build date.
- Vite embeds build metadata from Render's commit, then GitHub's commit, then `dev`; Settings uses generated copy.
