## Decisions / open issues
- The full Python run used pytest's default basetemp as requested. Seven tests needing `tmp_path` could not start because Windows denied access to the default temp root; I did not override it. The C33 database suite and migration round-trip pass.
- Render must have `STATEMENT_PASSWORD_KEY` set to a base64-encoded 32-byte key for password remembering. The reviewer has already configured it; no value is stored in the repository.
- Setup steps: in Money, open **Settings -> Get statements from Gmail**, create an upload key, and copy the generated script. Open **script.google.com**, create a project, and paste the script. Run `setup` and approve Google's access prompt. In Inbox, enter each statement password and review the result before saving. To stop, delete the daily Apps Script trigger and revoke the key in Settings. Use **Money -> Upload statement** whenever email import fails.
